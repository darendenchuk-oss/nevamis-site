# Reporting a security problem

If you find a security problem in nevamis.ca or app.nevamis.ca, please tell us
privately before telling anyone else.

- Email: sales@nevamis.ca, with "Security" in the subject line.
- Include what you found, the page or address involved, and the steps that show
  it. A screenshot or a short recording helps.

We read every report and will reply as soon as we can, usually within a few
business days.

## Please do not

- Send messages, calls, bookings or form submissions that reach real customers
  or prospects, or that create records in our systems, beyond the minimum
  needed to show the problem.
- Run automated scanners, load tests or anything that degrades the service.
- Access, keep or share data that is not yours.

## Scope

In scope: nevamis.ca, www.nevamis.ca, app.nevamis.ca, and the code in this
repository. Out of scope: third-party services we use (Cal.com, ElevenLabs,
Twilio, Stripe, GitHub, Vercel); report those to the provider.
